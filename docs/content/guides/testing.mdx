# Testing

We use Vitest for unit tests and Playwright for E2E tests.

## Unit & Component Tests (Vitest)

- Run tests: `pnpm test`
- Coverage: `pnpm test:coverage`
- Location: Colocated with source, e.g., `src/components/Navbar/__tests__/index.test.tsx`.

## End-to-End Tests (Playwright)

- Run tests: `pnpm test:e2e`
- Interactive mode: `pnpm test:e2e:ui`
- Location: `tests/e2e/`.

Accessibility testing is integrated into E2E tests via `@axe-core/playwright`.
