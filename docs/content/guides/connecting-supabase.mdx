# Connecting Supabase

Cur8d comes with a pre-configured Supabase integration stub.

## Setup

1.  **Environment Variables**: Ensure `NEXT_PUBLIC_SUPABASE_URL` and `NEXT_PUBLIC_SUPABASE_ANON_KEY` are set.
2.  **Server Client**: Use `src/lib/supabase/server.ts` for Server Components and Route Handlers.
3.  **Browser Client**: Use `src/lib/supabase/client.ts` for Client Components.
4.  **Types**: Generate database types using the Supabase CLI:
    ```bash
    supabase gen types typescript --project-id your-project-id > src/types/database.ts
    ```

Refer to `src/lib/data/README.md` for detailed data migration steps.
