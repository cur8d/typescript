# Keyboard Shortcuts

All registered keyboard shortcuts in blueprint.

| Shortcut | Key | Label |
| :--- | :--- | :--- |
| Search | `⌘K` / `Ctrl+K` | Open Search Palette |
| Help | `?` | Open Help Modal |
| Close | `Esc` | Close Modal / Palette |

Shortcuts are managed in `src/config/shortcuts.ts`.
