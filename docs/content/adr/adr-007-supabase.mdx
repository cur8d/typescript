# ADR-007: Supabase over Firebase
Status: Accepted

## Context
We need a robust backend-as-a-service for data, auth, and storage.

## Decision
We chose Supabase.

## Rationale
Supabase provides a powerful Postgres database, excellent TypeScript support, and a more developer-friendly SQL-based approach compared to Firebase's NoSQL Firestore.

## Consequences
The project includes a Supabase integration stub in `src/lib/supabase/`.
